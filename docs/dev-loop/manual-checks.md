# DAW での手動確認表（AC-23）

Fender Studio Pro で、Lesson EQ と Lesson Comp を確かめる。セッションの中の試験では確かめられないもの（ホストの中での振る舞い、耳、手の操作）だけを並べた。結果の欄に ○・×・気づいたことを書く。

## 準備

1. `tools\build.cmd Release` のあと `tools\install-vst3.cmd` で入れる（管理者の確認が出る。Studio Pro は閉じておく）。
2. Studio Pro を開き、プラグインの一覧を読み直して、「Personal」の下に Lesson EQ と Lesson Comp が出ることを確かめる。
3. 音の入ったオーディオのトラックを 1 本用意する（ドラムのループとボーカルなど、強弱のあるもの）。

## 確認すること

| # | 手順 | 期待すること | 結果 |
| --- | --- | --- | --- |
| 1 | トラックに Lesson EQ を挿し、窓を開く | Web アプリの EQ の大きい画面が出る。書体が Zen Kaku Gothic New（日本語）と IBM Plex Mono（数字）で、PRAYROOM の部品で描かれる | |
| 2 | ネットを切って（Wi-Fi を切る）Studio Pro を開き直し、1 をもう一度 | 書体も部品も同じに出る | |
| 3 | 再生する | スペクトル（入力と出力）が動く。止めると 0.2 秒ほどで止まる | |
| 4 | ベル 1 の Gain をつまみで +12 dB にする | 300 Hz のあたりが持ち上がって聞こえる。Auto Gain の数字が −3 dB 前後になり、全体の音量はあまり変わらない | |
| 5 | Auto Gain を切る | ベルの分だけ音量が上がる | |
| 6 | 窓の右上の電源（またはホストのバイパス）を切り替える | かける前の音とかけた後の音が、プチっという音なしで切り替わる。ホストのバイパスの表示と電源のスイッチがそろう | |
| 7 | つまみを 1 回ドラッグしてから、Studio Pro の取り消し（Ctrl+Z）を 1 回 | ドラッグ全体が 1 回で戻る | |
| 8 | グラフの点（ベル 2）をドラッグする | 点が動き、つまみの値も動く。Studio Pro のオートメーションを書き込みにしておくと、ドラッグのあいだだけ書かれる | |
| 9 | つまみの上でホイールを回す（数回） | 少しずつ動く。取り消しで、回した分がまとめて戻る | |
| 10 | つまみをダブルクリックする | 初期値に戻る | |
| 11 | つまみの下の値をクリックして、`2k` と打って Enter（Freq）、`abc` と打って Enter | 2 kHz になる。`abc` では元の値のまま | |
| 12 | 窓の中をクリックしてから、スペースキーを押す | Studio Pro の再生・停止が効く（キーボードはホストに残る） | |
| 13 | オートメーションのレーンで Bell 1 Gain を描いて再生する | つまみとカーブがレーンに合わせて動く | |
| 14 | 「設定」で拡大率を 150 % にする | 窓が 1.5 倍になり、文字と線がぼやけない。画面に収まらない拡大率は選べない | |
| 15 | 「設定」でテーマを Dark・Studio にする、説明の欄を「出さない」にする | すぐに切り替わる | |
| 16 | 窓を閉じて開き直す。Studio Pro を閉じて開き直す | 14・15 の拡大率・テーマ・説明の欄のまま開く | |
| 17 | 14・15 を変えたあと、別のトラックの Lesson Comp を開く | 拡大率とテーマが同じものになっている（説明の欄も同じ） | |
| 18 | ソングを保存して開き直す | つまみの値が全部戻る（拡大率・テーマはソングに入らない） | |
| 19 | Lesson Comp を挿し、Threshold −24 dB・Ratio 4:1 で再生する | 音量の流れのグラフが右から左へ流れ、GR が出る。Auto Gain が +9.0 dB 前後 | |
| 20 | Lesson Comp のグラフの左端の三角（Threshold）を上下にドラッグする | Threshold のつまみと点線が一緒に動き、取り消しで 1 回で戻る | |
| 21 | Ratio・Attack・Release を動かして、つまみの下の札と、その下の 2 段目の言葉を見る | Web アプリと同じ言葉が出る（例: 4:1・3 ms・200 ms で「音量を揃える」「出だしを残す」「拍に合わせる」と「ドラムにおすすめ」） | |
| 22 | オーディオの設定でサンプルレートを 44.1・96 kHz に替えて再生する | 音もスペクトルもグラフも崩れない | |
| 23 | Lesson EQ と Lesson Comp を 5 本ずつ挿して再生する | Studio Pro の CPU の表示が目立って上がらない。窓を閉じるとさらに下がる | |
