## 音の基準

音は Web アプリと同じにする。同じ設定で同じ入力を通したとき、出力が Web アプリの出力と数値で合うこと（AC-06、AC-07）。

- EQ: Web アプリは Web Audio の `BiquadFilterNode` を 13 段つないでいる（HP 4 段、LS、ベル 3、HS、LP 4 段）。係数の式と計算の精度は Chrome の実装（Blink の `biquad.cc`、`biquad_filter_handler.cc`）に合わせる。比べる相手は、Edge（Chromium）の `OfflineAudioContext` で Web アプリの `EqFilters` を鳴らした出力。
- コンプ: Web アプリの `CompressorCore`（`src/dsp.ts`）と AudioWorklet（`src/compressor.worklet.ts`）。ピーク、20 ms 保持、ニーなし、dB の上で Attack・Release。比べる相手は、Node で `CompressorCore` をワークレットと同じ形（128 サンプルのブロック、パラメータは float32）で鳴らした出力。
- 音が変わる近似や仕様の変更は、ユーザーの承認を取ってから入れる。

### Auto Gain の式

- コンプ: 0 dBFS の音が受ける GR の半分を足す。`makeup = min(24, targetGr(0, Threshold, Ratio) / 2)`。`targetGr` は Web アプリの式（∞:1 では超えた分の全部）。例: Threshold −28 dB・4:1 で +10.5 dB、−20 dB・4:1 で +7.5 dB。
- EQ: ピンクノイズを EQ のカーブに通したときの大きさの変化を、K 特性（BS.1770。Web アプリの `kWeighting` と同じ係数）で重み付けして打ち消す。`makeup = −10·log10( Σ |H(f)|²·|K(f)|² / Σ |K(f)|² )`。和は 20 Hz〜20 kHz の対数で等間隔の点でとる（ピンクノイズは 1 オクターブあたりの強さが同じなので、対数の格子では重みが同じ）。上下 24 dB で頭打ちにする。例（48 kHz）: ベル 300 Hz +12 dB Q 1 で −3.08 dB、HS 8 kHz +6 dB で −2.14 dB、HP 80 Hz 24 dB/oct で +0.20 dB。
- どちらも Auto Gain のスイッチ（パラメータ）でオン・オフできる。オフのときは 0 dB。持ち上げた量は、スイッチの下に出す（オフのときも計算した量を出す。Web アプリと同じ）。

## 入出力

- モノラル→モノラル、ステレオ→ステレオ。コンプは Web アプリと同じく全チャンネルのピークでかける（ステレオでリンク）。
- サイドチェイン、MIDI はなし。
- サンプルレートは 44.1〜192 kHz。ブロックの長さは問わない（1 サンプルから）。
- レイテンシは 0。

### 値の文字

画面とホスト（`getText`）で同じ文字にする。書式は Web アプリの `fmtDb`・`fmtHz`・ms・比率・Q と同じ（`-18.0 dB`、`47.5 Hz`、`2.50 kHz`、`10.0 ms`、`4.0:1`、`∞:1`、`最速`、`1.00`）。Slope は `24 dB/oct`、オン・オフは `On`・`Off`。数値の入力は behavior.md のとおり読む（単位は省略可、`k` は 1000 倍、範囲の外は端に丸める）。`∞`・`inf` は ∞:1、`最速`・`0` は最速として読む。

## 画面

- PRAYROOM のプラグインのウィンドウ（ヘッダー・本体・フッター）。ヘッダーの左にプラグイン名、右に設定のメニューと電源のスイッチ（バイパス）。
- Lesson EQ の本体: Web アプリの EQ と同じもの。グラフ（処理前と後のスペクトル、カーブ、バンドの点、上下 2 段の言葉 `TOP_LABELS`・`BOTTOM_LABELS`、周波数の色分け）、バンドの選択、選んだバンドのつまみ（On、Freq、Gain か Slope、Q）、Auto Gain のキーと量。
- Lesson Comp の本体: Web アプリのコンプと同じもの。入力→出力のグラフ、音量の流れ（入力・出力・GR の直近 4 秒、Threshold の点線とそのドラッグ）、GR のメーター、つまみ 4 つ、Auto Gain のキーと量、つまみの下の札（Ratio・Attack・Release の 3 語）と括弧の中の組み合わせの言葉（`src/character.ts` の表と区切りのまま）。
- 説明の欄（Hint）: 部品に乗ると、Web アプリと同じ文を出す。設定のメニューで出す・出さないを切り替えられる（既定は出す）。
- 設定のメニュー: 拡大率（100・125・150・200%）、テーマ（light・dark・studio）、説明の欄の表示。PC ごとの設定として `%APPDATA%\PRAYROOM\settings.json` に保存する（セッションには入れない）。
- 操作: つまみは上下ドラッグ、Shift で微調整、ダブルクリックで初期値に戻す、値の表示をクリックして数値を入力する。グラフの点のドラッグ、ベルの上でホイールで Q、Threshold の点線のドラッグも Web アプリと同じ。
- 入れないもの: プリセット、A/B、右クリックのメニュー（ユーザーの選択、2026-10-31）。

## 運用と互換

- 状態の保存と復元: すべてのパラメータを、版番号つきで保存する。
- 音は UI に頼らない。UI を閉じても音は変わらない。WebView が読み込めなくても音は止めない。
- UI はネットにつながなくても動く（書体の woff2 と部品をプラグインに入れる）。

## PRAYROOM の behavior.md と Web アプリの食い違い

ユーザーの指示（2026-10-31）:「音としてより良い方で」。止めたあとの音はどれも Web アプリと同じなので、動かしているあいだにプツッと鳴らない方を選んだ。

| 項目 | behavior.md | Web アプリ | このプラグイン |
| --- | --- | --- | --- |
| EQ の Freq・Gain・Q の平滑化 | 約 20 ms | 時定数 5 ms の指数 | Web アプリと同じ（98% まで約 20 ms。係数をサンプルごとに計算し直すので、ジッパーノイズも出ない） |
| コンプの Threshold・Ratio | 約 20 ms | 平滑化なし（128 サンプルごとに段で変わる） | 時定数 5 ms の指数を足す（Attack が最速のとき、段で GR が跳んでプツッと鳴るのを防ぐ） |
| コンプの Attack・Release | 約 20 ms | 平滑化なし | 平滑化なし（GR の動く速さを決める値なので、変えても音は跳ばない） |
| HP・LP のオン・オフと Slope | 約 10 ms のクロスフェード | 即座に切り替わる（プツッと鳴ることがある） | 10 ms のクロスフェード（behavior.md と同じ） |
| シェルフとベルのオン・オフ | 約 10 ms のクロスフェード | Gain を 0 dB へ時定数 5 ms で動かす | Web アプリと同じ |
| バイパス | 約 10 ms のクロスフェード | 時定数 5 ms の指数のクロスフェード | Web アプリと同じ |
| 比率の無限大の文字 | `inf:1` | `∞:1` | `∞:1`（音ではないので Web アプリのまま。入力では `inf` も読む） |
