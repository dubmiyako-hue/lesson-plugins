## reviewer の指摘と扱い

| # | 指摘 | 扱い |
| --- | --- | --- |
| 1 | 状態に無いパラメータは、既定値でなく今の値のまま残るはず（JUCE のソースを読んだ推定） | 当たらない。試験 `[state] a parameter the state lacks takes its default` を実際に回すと、0.25 に動かした `hs_gain` が既定値 0.5 に戻る。reviewer は実行していない |
| 2 | 読めない文字の試験が既定値のままで、何も確かめていない | 直した。先に別の値へ動かしてから読めない文字を渡す |
| 3 | `toFixed(-0.0)` が `-0.0` になる（JS は `0.0`）。今は届く経路なし | 直した。絶対値をとってから書く。試験を足した（ゴールデンは `${-0}` が `0` になるので持てない） |

## そのほか、試験で見つかったもの

- Steinberg の validator が「Program 000 に名前がない」で 1 件落ちた。`getProgramName` が `Default` を返すようにした。
- `Bell 1 Q` は 8 文字ちょうどなので、短い名前を聞かれても長い名前が返っていた。8 文字以下を聞かれたら、常に表の短い名前（`B1 Q`）を返すようにした。
