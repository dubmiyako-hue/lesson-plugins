## 設計書との食い違い（直した）

- 2.3: 部分最大は double とあったが、実装は float（float の最大なので結果は同じ）。設計書を実装に合わせた。
- 2.4: H は「13 段」とあったが、実装は効いている段だけ（Web アプリの `EqFilters.active` と Python の参照に合わせた）。設計書を直した。
- 9: AC-10 の入力は `autogain.json` とあったが、実物は `autogain.tsv`。
- 鳴っている Web アプリでは、HP・LP をオフにした段の周波数が 350 Hz に戻らない（`retype` が frequency を触らない）。素通しの段なので音の差は 1e-16 程度。設計書に注を足した。
